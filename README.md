# Lexify List Conversion

Key
Key for the system used to categorise lexical sets
Spaces/Semi-colons: If two or more lexical sets are separated by a space or semi-colon, the word contains all given sets
Example -  registration DRESS FACE (has both lexical sets in it)
Example - registration DRESS; FACE (has both lexical sets in it)

Paratheses: If a lexical set is put in parentheses this meantimes sometimes this word has this set, sometimes it does not. 
Example - jewelry GOOSE, (LETTER) HAPPY (this word always has GOOSE and HAPPY, and in some accents it can have LETTER as well)

Slash: If there is a / between two lexical sets, the word either contains one lexical set or another, but not both. 
Example - anti TRAP FLEECE/PRICE (depending on the accent, this word is either TRAP and FLEECE, or TRAP and PRICE)

Formatting Differences Between lists
List of 10,000: This list is currently formatted as “LEXICAL SET: word” for most of the words, with a space between each lexical set in that word (“DRESS LOT: electronic”). Otherwise this list follows the key above. However, not all the lexical sets have a colon after them. Also, some words have a number after them in brackets (“GOAT/LOT FLEECE nokia (#1335)”), the numbers can be ignored, and should eventually be deleted.

Lexical Sets from Book: This list is currently formatted as “word: LEXICAL SET” with a semi colon between each lexical set in that word (“a-level : DRESS ; FACE”). Otherwise this list follows the key above.

Common Missing Words: This list is formatted the same as the ‘Lexical Sets from Book’ list. However, there is no colon after the word (“adipex TRAP KIT DRESS”) and it is inconsistent with whether there is a space between lexical sets or a semi colon.

Scowl20 document: This list is formatted the same as the ‘Lexical Sets from Book’ list. However there is no colon after the word.
